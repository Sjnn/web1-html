# HTML Learning Project

This project contains examples of all basic HTML topics from W3Schools.

## Topics Covered:
- Headings
- Paragraphs
- Links
- Images
- Tables
- Forms
- Lists
- Formatting
- Comments
- Colors
- Div, Class, ID
- Buttons
- Iframe
- Video & Audio
- SVG & Canvas
- Semantic HTML
- Head, Favicon
- File Paths
- Code Elements
- Charset
- Entities
- XHTML

## Purpose:
This project was created as a practice for learning HTML basics step by step.
